Hepatitis Patient Clustering — Code Walkthrough

Step 1: Import Libraries

We import the essential Python packages needed for data preprocessing, clustering, and visualization.
import pandas as pd
import numpy as np
from sklearn.preprocessing import LabelEncoder, StandardScaler
from sklearn.cluster import KMeans
from sklearn.decomposition import PCA
import matplotlib.pyplot as plt
  • pandas / numpy — handle dataset operations
  • LabelEncoder, StandardScaler — prepare data for ML
  • KMeans — clustering algorithm
  • PCA — reduce dimensions for visualization
  • matplotlib — generate cluster plots

Step 2: Load Dataset

We load the CSV data file into a DataFrame for processing.
df = pd.read_csv("HCV-Egy-Data.csv")
df.head()
  • Reads patient records into a structured table.
  • Allows further manipulation and exploration.

Step 3: Handle Missing Data

Missing values are removed to avoid computation errors.
df = df.dropna()
  • Ensures clean, reliable input.
  • Prevents missing entries from corrupting clustering results.

Step 4: Encode Categorical Data

Converts text labels into numeric form for ML processing.
le = LabelEncoder()
df['Category'] = le.fit_transform(df['Category'])
  • Machine learning models only work with numeric features.
  • Assigns each unique label a numeric value.

Step 5: Feature Selection

Selecting biomedical features relevant to liver function.
features = ['Age','ALB','ALT','AST','CHOL','CREA','WBC']
X = df[features]
  • Focuses model on medically meaningful biomarkers.
  • Removes unnecessary data noise.

Step 6: Feature Scaling

Standardizes data so all features contribute equally.
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)
  • Prevents large-scale features from dominating clustering.
  • Improves stability and reliability of K-Means.

Step 7: Apply K-Means Clustering

Grouping patients into clusters based on liver biomarkers.
kmeans = KMeans(n_clusters=3, random_state=42)
clusters = kmeans.fit_predict(X_scaled)
df['Cluster'] = clusters
  • Patients are grouped into health-risk categories.
  • Each cluster indicates similar health biomarker patterns.

Step 8: PCA for Visualization

Reducing to 2D to show how clusters separate visually.
pca = PCA(n_components=2)
pca_data = pca.fit_transform(X_scaled)
plt.scatter(pca_data[:,0], pca_data[:,1], c=clusters)
plt.title("Patient Clusters (PCA View)")
plt.show()
  • Makes high‑dimensional clustering easy to visualize.
  • Clear separation indicates meaningful clustering.
